DeepWave - manual install (use the Setup .exe instead if you can)

PLUGIN (FL Studio and other hosts)
  Copy the whole folder "DeepWave.vst3" into:  C:\Program Files\Common Files\VST3\
  Then rescan plugins in your host (FL Studio: Options > Manage plugins > Find installed plugins).

STANDALONE
  Double-click DeepWave.exe (put it wherever you like).

Windows may warn "Windows protected your PC" because the files are not code-signed:
click "More info", then "Run anyway".
