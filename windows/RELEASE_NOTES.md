## DeepWave for Windows (64-bit)

**Easiest:** download `DeepWave-Setup-*-x64.exe`, run it, and tick what you want (VST3 plugin for FL Studio and
other hosts, and/or the standalone app). Then in FL Studio: Options > Manage plugins > Find installed plugins.

`DeepWave-windows-x64.zip` is the manual version (copy `DeepWave.vst3` into `C:\Program Files\Common Files\VST3\`).

- VST3 (FL Studio 20.8+, Ableton Live, Reaper, Cubase, Bitwig, Studio One) and standalone `.exe`.
- No VST2: the VST2 SDK is discontinued, so VST3 is the supported format.
- The installer is **not code-signed**, so Windows SmartScreen may say "Windows protected your PC":
  click *More info* then *Run anyway*.
